# 2026-10-10 工作记录与关键决策

## 004 英语对话助手 (English Tutor) 升级
- **解码器工业级重构**: 废弃 `minimp3`（避免无硬件 FPU 下软浮点计算的高开销及每帧 malloc 导致 I2S 欠载），引入嵌入式工业级定点数解码器 `libhelix-mp3` 作为组件 (`components/helix-mp3`)。播放生命周期内单次分配，解码全过程零动态内存申请。
- **流式边下边播**: 采用 HTTP chunked 边接收边定点解码边推送 I2S 机制，解决 32KB 内存截断问题，首包延迟降低至数百毫秒，支持 OK 键随时打断（Barge-in）。
- **口语对练交互升级**:
  - TTS 服务端点切换为 Edge-TTS (`http://192.168.31.170:5050/v1/audio/speech`)，音色采用 `en-US-JennyNeural`。
  - Prompt 升级为口语私教 Jenny，返回 JSON 包含 `user_text`（用户转写）、`tip`（语法/地道表达纠错）、`reply`（不超过 20 词的口语交流）。
  - UI 增加黄色语法建议横幅条 `Tip: ...` 以及右下角 5 柱声波律动像素动效（Audio Visualizer）。
- **CLIProxyAPI v8 鉴权问题定位**:
  - CLIProxyAPI v8.0.20 将客户端 API Key 规范由根级 `api-keys:` 调整为 `access.api-keys:`。已更新 `/opt/homebrew/etc/cliproxyapi.conf` 并重启服务，修复导致 ESP32 访问 8317 报错 401 Unauthorized（提示网络慢）的问题。
  - 针对大模型返回的 ```` ```json ```` Markdown 围栏符号增加清洗逻辑，防止 JSON 解析失败与异常字符乱码。

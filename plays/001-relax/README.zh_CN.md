# 001 - 休闲时刻 (Relax Time)

基于 FoloToy AI Passport (ESP32-C3) 打造的随机休闲专注伴侣玩具固件。

## 1. 功能简介与玩法定位

- **随机休闲抽签**：点击 OK 键，随机从 15、20、25、30 分钟中抽取一个休息/专注时长，并在屏幕上呈现动态倒计时。
- **动态微调机制**：倒计时期间支持仅限一次的手动增减机会（按 UP +5分钟，按 DOWN -5分钟）。
- **结束提醒与真人语音播报**：倒计时结束时，屏幕全屏高亮跳动提示，并自动播放真人中文语音：“休息结束了，该干嘛干嘛去~”。
- **全屏集成状态栏**：右上角集成时钟（开机自动通过后台 Wi-Fi 连接 SNTP 同步北京时间）与紧凑型 10px 电池电量动态显示（低电量红色高亮提示）。
- **完整中文字库**：内嵌基于思源黑体（Source Han Sans SC）提取的专用 14px 矢量抗锯齿 CJK 字库，彻底杜绝乱码。

## 2. 操作按键指南

| 按键 | 动作 | 功能说明 |
| --- | --- | --- |
| **OK (确定)** | 短按 | 在初始页开始随机抽签 / 运行中暂停或继续倒计时 |
| **OK (确定)** | 长按 | 退出应用，返回主菜单 |
| **UP (上键)** | 短按 | 增加 5 分钟时长（仅限调整一次） |
| **DOWN (下键)** | 短按 | 减少 5 分钟时长（仅限调整一次） |

## 3. 代码与模块组织

本玩法代码位于工程 `main/` 目录下：
- `main/demo_relax.c`: 核心状态机、倒计时逻辑与页面交互
- `main/voice_prompt.c` / `main/voice_prompt.h`: 真人提示语音 PCM 数组与后台 I2S 异步音频任务
- `main/status_bar.c` / `main/status_bar.h`: 右上角时间与电量一体化状态栏挂载组件
- `main/time_manager.c` / `main/time_manager.h`: Wi-Fi 自动连接与阿里云/NTP 北京时间后台同步
- `main/font_chinese_14.c` / `main/font_chinese_14.h`: 提取并生成的定制全字集 14px 中文字体

# 002 - 剪子包袱锤 (Rock Paper Scissors)

基于 FoloToy AI Passport (ESP32-C3) 打造的双人猜拳对决小游戏，支持多级智能 AI、常驻顶部比分与纯图形极简卡片展示。

## 1. 游戏特色与界面设计

- **屏幕上方常驻比分**：在屏幕标题下方新增白底比分横幅（例如：`比分: 你 3 - 1 电脑 (0平) 普通`），实时追踪对战胜负走势。
- **纯像素图形卡片**：取消了剪刀、石头、布图片下方的冗余中文标注，采用 64x60 大尺寸像素纯图形呈现（红柄金属剪刀、立体多面体岩石、折角格子布手帕），画面极简利落。
- **全字集 14px 思源抗锯齿中文字库**：提取全量 736 个项目字符（涵盖所有中文字符、偏僻字与中文标点 `【】`、`·`、`：` 等），彻底告别方块乱码。
- **多难度 AI 对弈系统**：
  - 🟢 **简单模式**：电脑温和放水（约 60% 概率出被玩家克制的牌），胜率高。
  - 🟡 **普通模式**：经典公平对战，1/3 纯随机盲猜，双方胜负几率均等。
  - 🔴 **困难模式**：进阶心理预判与出牌习惯统计算法（博弈论心理学：利用赢家守成、输家变阵惯性，结合玩家偏好频次针对性克制）。
- **暗中秘密出拳（防作弊）**：开局或新一轮时电脑在后台秘密选好，屏幕绝不提前泄露。
- **克制规则判定与动画**：
  - **剪刀剪布**（剪刀胜）
  - **布包石头**（布胜）
  - **石头打碎剪刀**（石头胜）
  - 玩家获胜时小电视机器人兴奋跳跃庆祝，展示详细战况描述。

## 2. 操作按键指南

| 按键 | 触发方式 | 功能说明 |
| --- | --- | --- |
| **UP** | 长按 或 双击 | **切换游戏难度**（简单 ⇄ 普通 ⇄ 困难） |
| **UP / DOWN** | 单击短按 | 选牌中切换选择（剪刀 / 石头 / 布） |
| **OK (确定)** | 单击短按 | 选牌时：确认出拳并同时开牌<br>开牌后：快速开启下一局 |
| **OK (确定)** | 长按 | 统一退出，返回主菜单 |

# 004-voice-assistant (English Tutor / 英语对话助手)

基于 ESP32-C3 + ES8311 音频 Codec 实现的随身口语私教与英语对话助手。

## 核心特性
- **外教角色设定**：大模型扮演热情鼓励的英语口语陪练 Jenny。
- **纯正 Edge-TTS 发音**：
  - 端点：`http://192.168.31.170:5050/v1/audio/speech`
  - 默认音色：`en-US-JennyNeural`（自然美式女声）
  - 模型：`tts-1`
- **低延迟双工交互**：
  - 板载麦克风 8kHz 采集录音；
  - 局域网大模型语音识别转写与简明英文回复（25 词以内短句）；
  - 本地软解 MP3 流式播放，支持按 OK 键即时打断（Barge-in）。
- **彩屏双语对照与转写**：
  - 屏幕同步呈现用户说的英文转写与外教 Jenny 的回复。

## 操作指南
- **OK 键（单击）**：开始倾听说话（3 秒录音），播报中按 OK 键可立即打断。
- **长按 OK 键**：退出并返回主菜单。

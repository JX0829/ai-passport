# 005-yes-no (Decision Coin · 3D Pixel Flip)

A decision-making toy for ESP32-C3 featuring a pseudo-3D pixel coin flip animation.

## Features
- Dynamic 3D perspective coin flipping simulation (multi-phase scale projection).
- Golden coin for **YES** and copper coin for **NO**.
- Real-time statistics: total spins, YES count, NO count.
- Animated pixel mascot with interactive jump feedback.
- Non-blocking button handling and smooth 60ms frame rate.

## Controls
- **OK**: Flip the coin / re-flip.
- **UP / DOWN**: Mascot jump.
- **OK (Long Press)**: Return to main menu.

# 005-yes-no (决策硬币 · 3D像素翻转)

专为 ESP32-C3 打造的拟真 3D 像素金币翻转与命运决策工具。

## 核心特性
- **3D 像素透视翻转动效**：8 相位椭圆纵向压缩展开投影，呈现流畅的立体旋转与重力回弹下落质感。
- **正反面双色金属质感**：
  - **YES（正面）**：亮金配色（`#FFD700`）+ 翠绿字样；
  - **NO（背面）**：古铜金配色（`#F4A460`）+ 珊瑚红字样。
- **实时决策统计**：顶部自动记录总投掷次数与 YES / NO 频率。
- **趣味神明评语**：随机揭晓定制的幽默决策指引。
- **互动吉祥物**：结果揭晓时配合跳跃庆祝与心情反馈。

## 操作指南
- **OK 键（单击）**：抛掷硬币 / 再次决策。
- **UP / DOWN 键**：吉祥物互动跳跃。
- **OK 键（长按）**：返回主菜单。

# 出题 (generate_questions)

根据用户**必须指定**目录下的已有的错题分析报告（`.md`文件）、知识图谱或学科总结文档，智能出具一份时长在 30 分钟以内的针对性练习题，并最终输出为 PDF 格式。

出题的优先级策略如下（**注意增加随机性**，不要每次都只挑前几个错题出）：
1. **最高优先级**：近期错题（从 `.md` 文件中提取的错误类型和相关考点）。必须确保每道错题都有 1-2 道变式训练题，直接针对学生的具体错因（如：进位遗漏、看错符号等）。**如果错题较多，请随机抽取不同类型的错题进行组合**，确保每次生成的练习卷具有新鲜感和覆盖面。
2. **次高优先级**：重难点（从卷面整体分析、知识图谱、学科总结中提炼的“重点”和“难点”）。**同样需要随机挑选不同的重难点**。
3. **普通优先级**：相关的常规知识点巩固。

---

## 触发场景与条件

当用户发出以下类似指令时启动此 skill：
- "/出题 ./小学/二年级下/数学/学习单/"
- "根据 ./小学/二年级下/英语/ 目录下的内容出一份练习卷"

**🛑 必须校验**：必须检查用户是否在 prompt 中明确指定了文件目录。如果用户**没有**指定目录，必须中止流程并提示用户：*"请提供包含错题或知识点文件的指定目录路径，例如：/出题 ./小学/二年级下/数学/"*。

---

## 工作流程

1. **校验输入** — 检查用户是否提供了目录路径。没有则提示补充。
2. **读取上下文** — 
   - 扫描该目录下的 `.md` 文件，重点提取其中的【错因及重难点分析】、【考点】以及元数据中的【学科】。
   - 若同目录下或关联路径存在知识图谱或学科总结文档，一并读取作为出题大纲。
3. **设计题目 (限时 30 分钟)** — 
   - 按照优先级策略（错题 > 重难点 > 常规知识点）设计新的变式题目。
   - **时间控制**：请预估每道题目的完成耗时，并控制总题量，确保整份测试题的完成时长在 **30 分钟以内**。
   - 题型应与原错题一致，或者采用更能准确考察该考点的题型（必须变式，不得照搬原题）。
4. **生成 Markdown 中间文件** — 
   - 将题目和答案分开生成为**两个**独立的结构化 Markdown 文件。
   - 题目文件命名为：`练习卷_YYYYMMDD_随机标识.md`
   - 答案文件命名为：`练习卷_YYYYMMDD_随机标识_答案.md`
5. **输出并转换为 PDF** — 
   - **输出目录**：将文件保存到 `用户指定目录/study-practice/{学科}/` 文件夹下（若目录不存在则自动创建）。
   - **格式转换**：调用技能目录下的 PDF 生成脚本（即 `.agents/skills/generate_questions/md2pdf.py`），**仅将题目的 Markdown 文件转换为 PDF 格式**。答案文件保留为 Markdown 格式，不需要转换。
   - 最终呈现给用户的必须是完成生成的 **题目 PDF 文件**和对应的**答案 md 文件**。

---

## 输出格式规范 (Markdown 中间格式)

**文件 1：题目文件 (`练习卷_YYYYMMDD_随机标识.md`)**
```markdown
# 针对性练习题 (预计完成时间: 30 分钟)

> 💡 **出题说明**：本套练习重点针对 [错题/知识点名称] 进行巩固训练，旨在解决 [具体错因]。

## 📝 练习部分

**1. [题型，如：填空题 / 计算题]** (预计耗时: 5分钟)
- [变式题 1，针对错题 A 的核心错因]

**2. [题型]** (预计耗时: 8分钟)
- [变式题 2，针对难点 B]
```

**文件 2：答案文件 (`练习卷_YYYYMMDD_随机标识_答案.md`)**
```markdown
# 答案与解析

**1. [题型]答案**
- [答案]
  > **解析**：[详细解释解题步骤，并点明如何避免之前错题中的相同错误]
```

---

## 注意事项

- **语文默写词库限制**：若生成语文学科且涉及“默写词语”或“根据拼音写字词”题目，**必须且只能**从语文目录下的 `默写` 文件夹中提取相关词组，绝对不要使用该范围外的任何词语。
- **强制输出题目 PDF**：生成的练习卷必须是 PDF 格式交付，以方便打印和直接使用；而答案文件保持 Markdown。
- **目录校验不可忽略**：随时检查输入上下文，未指定目录一律拒绝出题。
- **解析详尽**：答案部分的解析必须点出学生在原错题中的易错点，起到真正的纠错复习作用。
